# Localizando o espaço público: Gentrification e cultura urbana

Apresentação em site (HTML, CSS e JS) sobre o artigo de Rogério Proença Leite
(*Revista Crítica de Ciências Sociais*, n. 83, 2008), com o Bairro do Recife Antigo
como estudo de caso. Trabalho para a disciplina História, Turismo e Cidades
(curso de Turismo, CEFET/RJ, 2026.2), tema "Cultura urbana e cidades".

Apresentação: Vera Lúcia Rocha Lopes.

## Conteúdo

21 slides, cerca de 40 minutos com o debate:

- **1 a 11:** o artigo, o caso do Recife Antigo e a teoria do autor (contra-usos, lugar, espaço público).
- **12 a 18:** pesquisa complementar: Lefebvre, Jacobs, Neil Smith, Sharon Zukin,
  Arantes/Vainer/Maricato, o Pelourinho (Salvador), o Ocupe Estelita (Recife, 2014),
  o Recife Antigo hoje e um quadro comparativo.
- **19 a 21:** perguntas para o turismo, conclusão com ponto para debate e referências.

## Como abrir

Abra o `index.html` no Chrome ou no Edge. A pasta `img/` precisa estar junto.

| Tecla | Ação |
|---|---|
| → / espaço / clique | avançar |
| ← | voltar |
| F ou botão no canto | tela cheia |
| N | notas do apresentador |
| P | modo apresentador (janela com notas e cronômetro) |

No celular: toque para avançar, toque na parte esquerda ou deslize para voltar.
Com o celular em pé, a apresentação gira para ocupar a tela inteira; é só virar o aparelho.

`index.html?todos#5` abre o slide 5 com todas as partes já reveladas.

## Arquivos

- `index.html`: os 21 slides e as notas da fala
- `style.css`, `script.js`: visual, animações, navegação e modo celular
- `img/`: fotos e vídeo
